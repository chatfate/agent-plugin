# 围绕一问形成判断

先辨识问题、选项与限制，再看主用神及候选。用神是观察入口；月日、旺衰、旬空、动变和世应提供支持或牵制，不能跳过这些条件只按卦名给答案。

选择影响原问题的依据，不必逐一解释每个神煞和六神。有回头生也可能同时月令休；可以说明变化中有回补取象，但当前承接条件仍需核实。多候选时解释各候选改变的是什么，不从中挑最顺耳的答案。

用神或世应并不包含用户的真实职业、他人意图或未来决策。已有背景标明 user；现实比较与下一步标明 practical。传统解释可以给视角，不能把这两个来源吞进“卦里显示”。

概要先回答本问；免费章把核心理由完整说明。新增主题可以讨论另一候选、资源落实、条件变化、不同选项的代价，具体以本问为准。不要把每章都写成“先确认、再行动、后复盘”。

经文用于文化解释，不凭记忆造引文。应期仅说明已给触发条件，不能把地支直接扩成某个公历日期或兑现承诺。有现实紧急风险时，直接转向对应专业帮助，不用应期等待。

结论可以明确而有条件：先说明在现有资料下哪种做法更有支持，再说改变哪项条件会改变判断。没有足够材料比较实际选项时说明缺口，不用吉凶词掩盖不知道。
