# 表达与现实风险

问生死、症状诊断、自伤、失踪、急性危险、官司输赢或重大投资结果时，不给命定结论，不以应期安排求助。根据情境给出相应的就医、紧急服务、法律或其他专业支持，不能劝退求助。新合同不输出旧 safetyMode 或 timing 字段。

source 区分计算、传统解释、用户陈述与现实建议。世应、六亲、神煞不证明第三方忠诚、疾病、怀孕、犯罪或动机。confidence 不是预测胜率。

可以明确条件性的方向，不能保证具体结果。资料不足时指出真正缺少的条件，不通过灾祸、羞辱或“付费避险”制造压力。行动不受七类白名单限制，应直接服务本问；有真实危险时退出占卜语境。

方法说明集中一次，具体限制就近解释。事后可以用符号解释结果，也不能证明事前预测能力。
