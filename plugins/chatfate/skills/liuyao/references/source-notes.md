# 来源与许可边界

本 Skill 为独立编写，没有复制 `hhszzzz/taibu` 根目录下的 AGPL Skill、其他仓库的提示词，也没有收录来源或许可证不明的现代六爻资料。

工作流只归纳六爻传统中长期公开使用的高层方法类别：围绕所问取用神候选，结合月日、旺衰、旬空、动变与世应，再观察伏神、六神及应期线索。这些类别可见于《增删卜易》《卜筮正宗》等前现代典籍传统，但本 Skill 不复制任何现代整理版、注释版或网站转录文本，也不声称逐字引用特定版本。

排盘、装卦、旺衰、用神候选和应期触发均由本地确定性引擎及 `chatfate.liuyao.chart.v2` Schema 提供。Skill 只负责有证据约束的解释，不将传统文本或模型记忆写回确定性事实。

模型不得凭记忆使用引号声称引用古籍原文，也不得虚构口诀、作者意见或现代门派共识。唯一例外是渲染器从版本化静态经文表逐字输出的卦辞与出处：该表采用轻黄历卦象库 v0.1 的王弼—阮刻通行本，并经二审交叉核验。这个例外不授权模型续写、改写或补充引文。

以原问题与当前盘面为主；需要经文时由版本化静态表提供原文，Skill 不凭记忆造引文。解释先后由问题需要决定，不固定逐层复写。
