# 来源说明

本 Skill 改造自 `jinchenma94/bazi-skill` 的工作流和参考材料，但不照搬其人工排盘步骤、历史事件校准、未经核验的权重或确定性断语。

上游固定版本：`bdd7f863d4450bf0e2fac84579ad6b45cfdfa25c`

本 Skill 的专业性来自更严格的事实分层、组合分析与证据约束，不来自堆叠口诀。当前实现只使用 `chatfate.bazi.chart.v2` 已给出的四柱、日主、五行计数、节气上下文、神煞、干支关系、流年与大运事实；未将上游或其他项目的人工推算结果并入确定性事实。

没有可核验的版本、篇章和位置时，不要使用引号声称引用《滴天髓》《穷通宝鉴》《三命通会》《子平真诠》等典籍原文。可以写“传统子平框架通常从月令与日主关系展开”，但不能虚构逐字引文。

四域映射表是 ChatFate 明确声明的传统子平对应口径：career 看官杀＋印＋食伤，wealth 看财＋食伤＋比劫，love 看日支＋财官并采用中性并观，health 看五行偏枯＋日主受克。它是产品解释口径，不是古籍逐字引文，也不得伪造出处。

完整来源和许可证记录位于插件根目录 `third_party/bazi-skill/`。
