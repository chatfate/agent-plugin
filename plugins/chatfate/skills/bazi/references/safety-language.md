# 表达的力度

传统解释不是现实测量。confidence 表示依据直接程度，不是预测准确率；支持与牵制各有作用时直接说明，不用大量“可能”代替解释。

不预测寿命、死亡、重大疾病、灾祸、犯罪、财富收益或他人敏感隐私。不用单个神煞制造恐惧，不以付费揭晓或开运消费解决虚构风险。健康现状依据症状和专业判断，不能按五行诊断。

有现实背景时可以提出相应的判断与行动，不限于某份动作白名单。例如学习题目选错与学习时间不足需要不同处理；没有根据时不要给貌似个性的处方。

方法限制集中说明一次，具体资料缺口放在影响判断的位置。面对真实医疗、安全、法律或重大财务问题，下一步以对应现实支持为主，不让命理替代专业帮助。
