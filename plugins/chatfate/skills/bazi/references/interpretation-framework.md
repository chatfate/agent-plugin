# 按问题组织八字解读

从日主与月令、显干与藏干、多个十神、柱间关系建立主线。四个表层火字不能直接变成“身强”；有金的藏干也不能变成“会发财”。一段解释应说明所用关系为什么与所问有关，而不是仅把术语翻译成好听的形容词。

有背景时，先区分来自用户的事实与传统解释。用户说自己反复修改作品，可以讨论方法缺口、完成标准等不同原因；不能声称出生时间证明用户有完美主义。没有背景时，提出可供核对的观察，不假定职业或婚恋状态。

两项依据表面相反时，检查它们是否谈同一件事、处于同一时间层。原局、年度和当天不能互相替代；合与冲可以同时存在，回避其中一项会让报告失真。它们没有公认的现实事件概率，不应相加成运势分数。

每日先讨论当天相对本命的关系，只保留与今天主题有关的内容。年度有节气月段资料时比较确实不同的月份关系；不要强写每月预测，也不把每个公历季度凑成一章。人生报告选择不同的主题，例如学习与表达、资源承接、亲密关系中的需要、已有阶段变化；没有依据的健康章可以不写。

完整预览章给出主要理由。新增章应回答免费内容尚未回答的问题，至少增加具体依据、条件区分、另一生活主题或对选项的实质比较。重复同一通用动作或增加免责声明不算深入。

判断句不等于确定性预言。可以明确说“在你给出的条件下，更值得先考虑……”，再说明什么信息会改变它。行动没有固定列表，允许不提供行动；有行动时，应适合用户真正要处理的事情。
